# 3CG · Concept Coverage From Competency Gap

3CG builds on [Competency Gaps](https://github.com/maty-bohacek/competency-gaps) to study benchmark fingerprints, complementary benchmark recommendation, and benchmark item pruning. Its Python package and command-line tool, **TriCG** (`tricg`), currently aggregate existing sparse autoencoder activations into coverage profiles and assemble a benchmark-by-concept matrix. Use [uv](https://docs.astral.sh/uv/) to get started with `uv sync --dev`, then try `uv run tricg profile examples/toy-benchmark.json` or follow the [data format and commands](docs/data-format.md). The [benchmark catalog](data/benchmarks.json) contains candidate datasets, and the included activation examples are synthetic. Model extraction, empirical reproduction, recommendation, and pruning remain upcoming work.
